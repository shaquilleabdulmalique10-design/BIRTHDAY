## 🚀 How to Use

### For End Users:
1. Open `home.html` in a web browser
2. Navigate to "Create Link" to generate birthday links
3. Use "Reminders" to set up email notifications
4. Share generated links via WhatsApp, Email, or copy/paste

### For Developers:
1. Follow `EMAILJS_SETUP.md` to configure email functionality
2. Replace placeholder EmailJS credentials in `email-reminders.js`
3. Deploy to any web server (no backend required)
